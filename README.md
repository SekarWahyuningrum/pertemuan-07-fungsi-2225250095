## Tujuan
* **Memahami Konsep Dasar Fungsi:** Mampu mendefinisikan (`def`) dan memanggil (*calling*) fungsi dalam Python untuk menghindari duplikasi kode.
* **Menguasai Parameter dan Argumen:** Memahami cara mengirim data ke dalam fungsi menggunakan parameter posisi, keyword argument, maupun *default argument*.
* **Mengimplementasikan Return Value:** Mampu mengembalikan nilai dari fungsi menggunakan kata kunci `return`, termasuk mengembalikan lebih dari satu nilai (*multiple return values*).
